# Call from The God

An Android Studio starter project for a Kendrapara, Odisha prayer-times app.

## Open and build
1. Extract this ZIP.
2. Open Android Studio.
3. Choose **Open** and select the extracted `Call_from_The_God` folder.
4. Allow Gradle sync to finish. Install Android SDK 35 if Android Studio asks.
5. Use **Build > Build APK(s)**.
6. The debug APK is normally created at `app/build/outputs/apk/debug/app-debug.apk`.

## Important prayer-time note
This starter uses a simple solar approximation and 18-degree Fajr/Isha angles with Hanafi Asr factor 2. It is not independently validated against an official local timetable. Please compare the times with a trusted Kendrapara mosque timetable before relying on them for worship.

## Project details
- App label: Call from The God
- Package: `com.callfromthegod.prayertimes`
- Minimum Android version: Android 8.0 (API 26)
- UI: XML layout with Kotlin Activity
